Overview
========

**NextGIS Toolbox on-premise** is a specialized web application deployed on the company's server. It gives users access to various tools for on-line data processing. 

Each tool performs one specific task, e.g. converts vector data format or calculates spectral albedo. Some of the tools are integrated with Web GIS. There are also highly specialized tools created to solve a specific problem on a specific data set.
